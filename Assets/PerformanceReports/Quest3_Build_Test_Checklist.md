# قائمة فحص البناء والاختبار — Meta Quest 3

> تُستخدم **بعد** موافقتك على البناء. لم يُنفَّذ أي Build في هذا التدقيق.

## أ. قبل البناء
- [ ] Build Target = Android، وQuest 3 متصل ووضع المطور مفعل
- [ ] OpenXR Android: Render Mode = Single Pass Instanced ✅ (مؤكد حاليًا)
- [ ] Meta Quest feature مفعل، و"Quest 3" محدد في Target Devices
- [ ] المشاهد في Build Settings: S1Test (الأول)، FireCenterLobby، Sample، demo_city_night
- [ ] **بناءان من نفس الـCommit:** Windows (السائق + G29) وAndroid APK (المساعد على Quest)
- [ ] لاعب Quest يختار مقعد المساعد (Assistant) دائمًا، فالسائق على Quest غير مدعوم بالتصميم
- [ ] أول بناء للقياس: **Development Build + Autoconnect Profiler** (وبناء Release منفصل للأرقام النهائية)
- [ ] إذن INTERNET وRECORD_AUDIO في الـManifest
- [ ] تسجيل: حجم الـAPK، ومدة البناء

## ب. أدوات تجهز قبل الاختبار
- [ ] OVR Metrics Tool مثبت مع Overlay (FPS، CPU/GPU Level، GPU %، Temp، Battery)
- [ ] `adb logcat -s VrApi Unity > quest_log.txt`
- [ ] Unity Profiler متصل (Development Build)
- [ ] Memory Profiler package (Snapshot لكل مرحلة)
- [ ] شحن البطارية >80% وتسجيل حرارة الغرفة

## ج. خطة اختبار 15–30 دقيقة (سجّل الأرقام في الجدول)

| الوقت | المرحلة | ماذا تفعل | ماذا تسجل |
|---|---|---|---|
| 0–2 د | تشغيل | فتح التطبيق | زمن الإقلاع، أول إطار، RAM (dumpsys) |
| 2–5 د | FireCenterLobby | جلوس في المقعدين، تبديل، Ready، البوت | FPS، GPU %، **ابحث عن أثر 37 ضوءًا** |
| 5–7 د | تحميل المحطة | شاشة التحميل | زمن التحميل، Hitch، RAM بعد التحميل |
| 7–11 د | المحطة | الإنذار، التابلت، الباب، الصعود للشاحنة | FPS، Stale frames |
| 11–13 د | تحميل المدينة | | **ذروة RAM**، زمن التحميل، هل فُرّغت المحطة؟ (Memory Snapshot) |
| 13–20 د | القيادة | صفارة، أضواء، طريق | FPS، CPU Main/Render، Draw calls |
| 20–27 د | الحريق | الخرطوم، المضخة، الماء على النار من قرب | **GPU % وOverdraw عند الوقوف أمام النار** |
| 27–30 د | الاسترجاع والنهاية | لف الخرطوم، النتيجة | Temp، CPU/GPU Level (هل حدث Throttling؟)، البطارية |

**كرر الاختبار:** (1) Solo مع البوت، (2) لاعبان على جهازين، (3) جلسة ثانية متتالية دون إعادة تشغيل الجهاز (اختبار حراري).

## هـ. معايير النجاح (للعرض)
- [ ] 72Hz ثابتة في معظم الوقت، والـStale frames < 1% (قياس)
- [ ] لا Crash ولا OOM خلال 30 دقيقة
- [ ] انتقالات بدون شاشة انتظار نظام Meta (لا تجمد > ~1–2 ث بدون شاشة تحميل)
- [ ] لا Throttling حراري يسقط الأداء تحت 72Hz
- [ ] صوت Vivox يعمل بين الجهازين، وزمن مزامنة الأفاتار مقبول
- [ ] Driver وAssistant يكملان المهمة كاملة

## و. الاختبار الوظيفي
- [ ] الجلوس بالمقاعد في الـLobby وفي الشاحنة، والرأس واليدان حرة دون اهتزاز عند الطرف الآخر
- [ ] المقود بالقرب (Snap) ودورانه في الاتجاه الصحيح
- [ ] النزول من الشاحنة: الجسم يخرج مع اللاعب
- [ ] الخرطوم، البكرة، المضخة، النوزل، وإطفاء النار
- [ ] الأسهم والتوهج بالألوان الصحيحة (أزرق Driver / أحمر Assistant)
- [ ] تتبع اليدين والكونترولر: Grab وTrigger/Pinch
- [ ] الأشياء الممسوكة لا تتحرك بالـJoystick
